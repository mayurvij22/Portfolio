## ✨ Highlights

- **Sections**: Home · About · Projects · Achievements · Contact · Friend Gallery
- **Dark / light theme** toggle (React Context)
- **Smooth animations** with Framer Motion and **3D tilt cards** with `react-parallax-tilt`
- **Smooth scrolling** navigation with `react-scroll`
- Links to my **resume**, GitHub, LinkedIn and LeetCode
- **Vercel Analytics** for visitor insights
- Fully responsive, mobile-first layout

## 🛠️ Tech stack

| Purpose | Technology |
|---|---|
| Framework | React 19 + Vite |
| Styling | Tailwind CSS |
| Animation | Framer Motion, react-parallax-tilt |
| Icons | lucide-react, react-icons |
| Hosting and analytics | Vercel, `@vercel/analytics` |

## 🚀 Run locally

```bash
git clone https://github.com/mayurvij22/Portfolio.git
cd Portfolio
npm install
npm run dev      # http://localhost:5173
```
